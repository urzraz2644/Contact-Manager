# Rolodex Contact Management Application

## Project Description

This project is a Java-based Rolodex Contact Management Application. The application allows users to manage different types of contacts while storing contact information in an SQLite database.

## Features

- Add contact
- Delete contacts
- Update contact phone numbers and email addresses
- Display all contcts
- Search for contacts by the first letter of the last name
- Support multiple contact types, including Personal, Family, Friend, and Business contacts
- Store and retrieve contact information using an SQLite database
- Continue running until the user chooses to exit

- ## Technologies Used

- Java
- SQLite
- JDBC
- Visual Studio Code
- Git and GitHub

- ## Project Summary

- The Rolodex Contact Management Application demonstrates object-oriented programming and database management concepts. The project uses Java classes, and interface, inheritance, polymorphism, composition, constructors, and access specifiers to organize contact information. SQLite provides persistent storage for the contacts. Users can add, delete, update, display, and search for contacts through a menu-driven interface.
